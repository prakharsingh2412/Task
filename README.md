# 6-Month Master Syllabus Dashboard

A self-contained, single-file HTML dashboard for tracking a **168-day full-stack learning roadmap** — from web foundations to Django, React + TypeScript, PostgreSQL, Redis, Docker, AWS, System Design, Go, startup building, and YouTube content creation.

The dashboard ships with **no build step, no dependencies, and no backend**. Just open the file — everything runs in the browser.

---

## Features

- **168-day syllabus** across 6 months × 4 weeks, pre-loaded
- **Interactive checkboxes** for every task
- **Live progress bar** — overall % + per-week completion
- **Persistent progress** via `localStorage` (survives page reloads)
- **Month tabs** to filter by month, or view all 168 days at once
- **Full-text search** across titles, tracks, and task descriptions
- **Deep study resources** auto-attached to every day (MDN, Django docs, Redis docs, Go tour, AWS docs, and more)
- **Dark / light theme** — automatic via OS preference, plus manual override
- **Print / Save as PDF** — clean print stylesheet included
- **Zero dependencies** — one HTML file, works offline
